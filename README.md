## 🚗 Featured Project — Night Drive

**Night Drive** is a 2D pixel-art driving prototype built with Godot.

The project includes:

- Three-lane player movement
- Random obstacle spawning
- Collision and life systems
- Temporary slowdown after collisions
- Pause, game over and restart systems
- Distance tracking
- Endless scrolling environments
- Reusable scenes, signals and timers
- Original pixel-art assets

🔗 [View Night Drive](https://github.com/GabrielAguiar1573/night-drive-godot)
